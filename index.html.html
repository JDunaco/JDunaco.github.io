About

I've spent my career so far in two lanes that turned out to be the same lane. One foot in game development — leading programming on two-week game jam teams, shipping playable builds under hard deadlines. rideshare-simulator/

RideShare Simulator

solo · data structures & algorithms capstone

A discrete-event simulation that dispatches cars to riders in real time. A Quadtree narrows candidates by geographic proximity; Dijkstra's algorithm picks the fastest car by actual road-network travel time. Includes a full CLI, seeded reproducible runs, correctness tests validating the Quadtree against a brute-force check on 5,000 random points, and an automated metrics/visualization pipeline.

Trash Panda Takeover

lead programmer · 3-person team · 2-week jam

A day/night dual-loop game built in Unity. By day, run a sandwich shop counter and serve customers. By night, scavenge the town for ingredients and build enough influence to convert humans into raccoons — three raccoons in a trenchcoat, back to work the counter with you. Led the team's programming: the shop-management loop, the day/night transition, and night-phase enemy/NPC behavior.
